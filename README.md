# My Writing Style Guide

Static GitHub Pages version of “Teach AI Your Personal Writing Style.”

## Repository

This package is configured for:

- Repository: `BobAinsworth/my-writing-style-guide`
- Published address: `https://bobainsworth.github.io/my-writing-style-guide/`

## Files

- `index.html` — page content
- `styles.css` — layout and responsive styling
- `script.js` — platform tabs and copy button
- `favicon.svg` — browser icon
- `fonts/` — local site fonts
- `.nojekyll` — prevents GitHub Pages from processing the site with Jekyll

All site references use relative paths, so the repository base path works without further edits.
